# 注册高德开发者

官方教程：https://lbs.amap.com/api/mcp-server/create-project-and-key

获取 key ，这里 key 不便展示，自行获取，

# dify 插件 - 安装支持 MCP 插件

在 dify 主页面，点击“插件”，点击“探索Marketplace”，输入并搜索“mcp”，安装“Agent 策略（支持 MCP 工具）”和“MCP SSE / StreamableHTTP”这两个插件，并确认状态为“已安装”，

回到“插件”页面，点击“MCP SSE / StreamableHTTP”插件，点击“API Key 授权配置”，输入“凭据名称”和“MCP 服务配置”，

- 凭据名称，自定义，这里调用高德地图开发者的出行`API Key`，可以自定义输入，如`gaode-map`，

- MCP 服务配置，示例如下，配置完成之后，点击“保存”，
```json
{   "mcpServers": {     "amap-amap-sse": {       "url": "https://mcp.amap.com/sse?key=<这里，替换为自行获取的 API Key 字符串>"     }   } }
```

## 构建智能体

创建空白应用，创建 Agent 应用，自定义应用名称&图标，自定义描述信息，配置完之后点击“创建”，

在智能体配置界面，“变量”、“知识库”以及“元数据过滤”无需设置保持默认，需要设置 LLM 以及添加 MCP 工具，

- 设置 LLM 这里不赘述，

- 添加 MCP 工具，点击添加“工具”，添加“插件”选择“发现和调用MCP”，添加全部 2 个插件，

  + mcp_sse 获取 MCP 工具列表，确认状态为“使能”，

  + mcp_sse 调用 MCP 工具，确认状态为“使能”，

开始“调测与预览”，输入相关的出行诉求，如，


# dify-知识库-图文知识库

## dify 图文知识库实现
在已实现的文本知识库基础上，希望知识库在回答的时候，除了输出文本之外还可以将图片展示出来，实现图文知识库的应用，

基于 **ChatFlow** 实现图文知识库的应用，创建及配置知识库方式相同，创建聊天助手方式使用**工作流编排**而不是默认的**基础编排**方式，

### 创建工作流编排聊天助手
**开始节点**接收用户输入的问题，给到**知识检索**，检索的结果丢给**LL**生成回答来识别文本、URL等不同类型内容，再给到**参数提取器**对不同类型的内容进行提取处理，通过**条件分支**时执行分支判断，

- 如果提取到了 URL，则通过**HTTP请求节点**处理 URL 并获取远程图片，将文本和图片结合，给到**直接回复**作为输出节点，

- 如果未提取到 URL，则将文本给到**直接回复**作为输出节点，

### 开始节点
用户输入

### 知识检索节点
将用户输入作为**查询文本**，设置**知识库**添加关联已有的 dify 知识库，并进行“召回设置”，查看输出变量示例，
```shell
result Array[Object]
召回的分段
  content string
  分段内容
  title string
  分段标题
  url string
  分段链接
  icon string
  分段图标
  metadata object
  其他元数据
  files Array[File]
  召回的文件
```

### LLM 节点
指定 LLM 模型并设置好推理后处理参数，接收**知识检索**节点的输出`result Array[Object]`作为**上下文**，在**System**中根据**上下文**对象数组数据类型设置好提示词用于指导解析。需要注意两点，

- 指定 LLM 模型设置好推理后处理参数，目的为了提升对话的精准度，需要设置下 LLM 的相关参数，如 TopK、温度等；

- 希望 LLM 输出的数据为 json 格式，所以需要在LLM节点做⼀些提示词限制；

示例，在**System**中输入的提示词如下，
```shell
注意，如果模型输出内容中包含URL，请将URL单独提取出来并采⽤一下格式输出：
{"Content": "示例输出内容", "URL":"URL"}
如果模型输出内容中不包含URL，请将模型输出内容按照以下格式输出：
{"Content": "示例输出内容"} 
请将模型结果以JSON格式输出，不要输出其他任何与JSON格式⽆关的内容。 
注意：URL以http或https开头
```

# dify-知识库-文本知识库

## 概述 - RAG

企业级私有知识库，不得不提到 RAG（检索生成增强），

准备好私有知识库，知识库数据存放在向量数据库中，这个向量数据库并不需要额外准备，dify 平台已经通过 docker-compose 部署完毕，

围绕这个向量数据库，将 RAG 分为两个主要部分，

- **数据工程**，导入知识库并解析到向量数据库中，

**Load Documents** -> **Unstructed Loader** -> **Text** -> **Text Splitter** -> **Text Chunks** -> **Embedding** -> **Vector Store**

把本地文档分割/拆块 -> Embedding 向量化 -> 批量写进向量数据库，建立近似最近邻索引，完成知识固化；

- **数据检索**，用户自然语言问题与知识库做相似性召回，获取最相关文本块送入 LLM 组织语言输出答案，

**Query** -> **Embedding** -> **Query Vector** -> **Vector Similarity** -> **Related Text Chunks** -> **Prompt Template** -> **Prompt** -> **LLM** -> **Answer**

用户问题即时向量化 -> 在向量数据库里做相似度 Top-K 召回 -> 把最相关文本块通过提示词工程转换为上下文送入 LLM -> 生成答案；

## dify 文本知识库实现

相比 RAG ，dify的优势在于，可实现 RAG 流⽔线上各环节的可视化，它提供了⼀套简单易⽤的⽤户界⾯⽅便应⽤构建者管理个⼈或者团队知识库，并能够将知识库快速的集成到 AI 应⽤中，

当下，dify 支持多种数据源格式，包括，

- ⻓⽂本内容： TXT、Markdown、DOCX、HTML、JSON、PDF  

- 结构化数据： CSV、Excel

另外，私有知识库要达到良好的效果，必须与 embedding 模型和 rerank 模型相结合，需要提前准备好相关模型与关联引入到 dify 模型仓中，

### 创建知识库

- 创建知识库：dify 主页面 -> 点击“知识库” -> 点击“创建知识库”，

- 选择数据源：导入已有文本，如将 “Finance_Career_FAQ.txt” 文本导入作为私有知识库原始文档，点击“下一步”，

- 分段设置：大模型存在上下文窗口，通常需要将整段文本进行分段处理后，将与用户问题关联度最高的几个段落召回。另外，用户问题与文本分段进行语义匹配时，合适的分段大小将有助于匹配关联性最高的文本内容，减少信息噪音，

  + “分段标识符”，设置为 `\n`；

  + “分段最大长度”，设置为 `500`；

  + “分段重叠长度”，设置为 `50`； --- 一般情况下，分段重叠长度大概设置为分段最大长度的10%~20%为宜，也不是完全绝对的，根据特定的文本设置即可；

  + “文本域处理规则”，默认勾选替换掉连续的空格、换行符和制表符，可选删除所有URL和电子邮件地址；

  + “使用 Q&A 分段”，默认可选，根据文本的内容决定，如果文档是问答类知识库可勾选，如果是一般性段落性文章，可不勾选； --- 如果勾选这个，则“索引方式”只能采用“高质量”，“经济”方式自动置灰；

实测，dify 1.11.2 版本，对于 Q&A 格式的 txt 文本，“使用 Q&A 分段”的方式，点击“预览块”无法显示预览结果。这里采用“默认可选”+“索引方式-高质量”往下走，

- 索引方式：索引⽅式决定数据匹配⽅式，索引策略与检索⽅式相关，根据场景需求来选择合适的索引⽅式。默认推荐“高质量”，

- Embedding 模型：这里使用已添加的 bge-large-zh-v1.5 模型，

- 检索设置：分为向量检索、全文检索和混合检索，

  + “向量检索”，通过生成查询嵌入的向量数据库，查询与其向量表示最相似的文本分段；

  + “全文检索”，检索文档中的所有词汇，允许用户查询任意词汇，并返回不包含这些词汇的文本片段；

  + “混合检索”，推荐方式，属于向量检索+全文检索，应用重排步骤，将两类检索结果中选择用户问题的最佳匹配。可设置权重以及配置重排模型，

      “权重设置”，默认权重设置为 0.7语义，0.3关键词，

      “rerank设置”，重排模型使用已添加的 bge-reranker-v2-m3 模型，

- 保存并处理：设置完成之后点击，开始嵌入解析文档。将会提示知识库已创建，待状态显示“嵌入已完成”，可“前往文档”，也可在“知识库”页签中查询已经创建的知识库，

### 创建对话应用并关联知识库
对于已经构建好的知识库，可以创建一个对话应用并关联知识库，

在 dify “主页”的“工作室”页签，点击“创建空白应用”，创建“聊天助手”，

- 关联 LLM ，可设置关联 LLM 并设置后处理参数，如 温度为0.1，Top P为0.9，

- 提示词，示例，如“这里是金融与职业规划行业小助手,请问有什么可以帮到的吗?”，不涉及变量的话，可不做变量设置与引入相关操作，

- 知识库，上下文可“添加”关联已有的知识库，并进行“召回设置”，

  + “召回设置”，当前 dify 1.11.2 默认情况下使用多路召回，支持从多个知识库中检索知识，然后重新排序；

  + “权重设置”，默认权重设置为 0.7语义，0.3关键词；

rerank 模型设置，关联重排模型，使用已添加的 bge-reranker-v2-m3 模型，设置 Top K 为 3，可使能 Score 阈值，如设置为 0.3，相似度小于0.3的结果可过滤掉；

- 聊天功能管理，与 bot 聊天，默认开启“引用和归属”显示回答引用的知识库来源，其他功能可按需进行使能，
